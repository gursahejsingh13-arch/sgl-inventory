# ============================================
# ADDITIONAL SETUP REQUIRED
# ============================================

# 1. MongoDB Atlas Account
#    - Create cluster at: https://www.mongodb.com/cloud/atlas
#    - Get connection string
#    - Add to .env as MONGODB_URI

# 2. Finnhub API Key
#    - Register at: https://finnhub.io/register
#    - Get free API key
#    - Add to .env as NEXT_PUBLIC_FINNHUB_API_KEY

# 3. Gemini AI API Key
#    - Go to: https://aistudio.google.com
#    - Create API key
#    - Add to .env as GEMINI_API_KEY

# 4. Gmail Account (for Nodemailer)
#    - Enable 2-Factor Authentication
#    - Generate App Password
#    - Add to .env as NODEMAILER_EMAIL and NODEMAILER_PASSWORD

# 5. Better Auth Secret
#    - Generate random 32-character string
#    - Add to .env as BETTER_AUTH_SECRET

# 6. Inngest Account
#    - Sign up at: https://www.inngest.com
#    - Create new app
#    - Configure webhook: https://yourdomain.com/api/inngest
#    - Run dev server: npx inngest-cli@latest dev

# ============================================
# TROUBLESHOOTING
# ============================================

# Issue: "Cannot find module..."
# Solution: Delete node_modules and package-lock.json, then run npm install

# Issue: MongoDB connection failed
# Solution: Check MONGODB_URI, whitelist IP address in MongoDB Atlas

# Issue: Finnhub API limit exceeded
# Solution: Wait for rate limit reset (1 minute), or upgrade plan

# Issue: Email not sending
# Solution: Verify Gmail App Password, check NODEMAILER credentials

# Issue: Build errors with TypeScript
# Solution: Check tsconfig.json, ensure all types are installed

# Issue: Inngest functions not running
# Solution: Start Inngest dev server: npx inngest-cli@latest dev
